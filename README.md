# 📈 Trading Chart Dashboard & AI Assistant

An interactive, high-performance web dashboard for institutional market structure analysis, technical pattern detection, and real-time chart insights.

---

## 🚀 Features

- **Interactive Charting:** Powered by TradingView charting technology for smooth multi-timeframe navigation.
- **Institutional SMC Detection:** Automated tracking of Fair Value Gaps (FVG), Liquidity Sweeps, and Previous Day High/Low (PDH/PDL) levels.
- **AI Chart Assistant Integration:** Real-time narrative analysis and risk management recommendations for trading sessions.
- **Modular Data Architecture:** Designed to connect seamlessly with MT5 REST/WebSocket feeds and custom quantitative backends.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+), TradingView Charting Libraries.
- **Backend:** Python, FastAPI, WebSockets.
- **Data & Execution:** MetaTrader 5 API, Custom Indicator Exporters.
